# Manipulate
Manipulate and Solve

A static, offline-friendly site that helps kids learn addition and subtraction with digital manipulatives.
Open `index.html` in a browser — no build step.

- Drag (or tap) 1s, 5s, 10s, 20s, 50s, 100s into a container with a goal number; overflow is rejected.
- Add or subtract a second container, then break both down by 10s / 5s / 1s with numeric notation.
- See the problem on a number line; subtraction also shows a "cross out" visual.
